

# TALPAD-BOOM-Developers

**为学而思 TALPAD 提供开源的底层开发与定制支持。**

我们是一个专注于 **TALPAD** 设备的开发者社区，致力于探索该硬件的潜力，补全缺失的底层组件，并推动第三方系统与功能的适配。

## 🛠️ 主要项目

- **[TALIH-PD2-Kernel](https://github.com/TALPAD-BOOM-Developers/TALIH-PD2-Kernel)**：TALIH-PD2 的内核源码仓库，已基本补全缺失部分，内核源码可用。
- **[TALIH-PD2-TWRP-Device-Tree](https://github.com/TALPAD-BOOM-Developers/TALIH-PD2-TWRP-Device-Tree)**：适用于 TALIH-PD2 的 TWRP 设备树，包含 Data 解密支持。
- **[TALIH-PD2-Kernel-Exp](https://github.com/TALPAD-BOOM-Developers/TALIH-PD2-Kernel-Exp)**：内核的实验性分支仓库，用于探索新功能与改进。
- **[TALIH-PD2-PenFix](https://github.com/TALPAD-BOOM-Developers/TALIH-PD2-PenFix)**：针对设备手写笔功能的修复与优化。
